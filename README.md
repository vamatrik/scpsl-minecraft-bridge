# SCP:SL × Minecraft

**Авторы: Claude x Vamatrik** · [English](README.en.md)

Две игры работают **одновременно** и каждая рисует своё:

* **Minecraft 26.3 (Fabric)** — мир, блоки, мобы, свет, небо, Незер, Энд, дракон;
* **SCP: Secret Laboratory** — твой персонаж, движение, оружие в руках, инвентарь, интерфейс, админ-панель (M).

Мост связывает логику: ходишь по блокам Minecraft с физикой SL, стреляешь — ломаешь блоки и ранишь мобов,
мобы бьют тебя (урон ×5 под 100 HP SL), подбираешь предметы на E, крафтишь в настоящем верстаке, плавишь в печке,
ходишь в Незер и Энд. **Клиент SCP:SL не модифицируется** — это обычная игра из Steam.

Весь мод (лаунчер, плагин SL, мод Minecraft) говорит **по-русски или по-английски** — язык выбирается внизу боковой панели лаунчера.

## Как это устроено

```
 SCP:SL (Steam, без изменений) ──игра── Dedicated Server + плагин LabAPI ──TCP 25599── Minecraft + мод Fabric
            │                                                                              │
            └──────── окно ─────►  оверлей (Windows Graphics Capture)  ◄────── окно ───────┘
```

| Часть | Папка | Что делает |
|---|---|---|
| Плагин SL (LabAPI) | `src/sl-plugin` | невидимые коллизии по блокам Minecraft, поза камеры, выстрелы, урон, предметы-стаки, меню, команды |
| Мод Minecraft (Fabric) | `src/fabric` | камера = камера SL, попадания, коллизии, предметы, окна MC, порталы, падение, броня |
| Оверлей | `src/compositor` | захват окон SL и Minecraft; где SL видит зелёный фон-ключ — подставляет Minecraft. Ввод идёт прямо в SL |
| Лаунчер | `src/launcher` | подготовка (поиск игр, установка мода/плагина), выбор/создание мира, запуск и остановка всего |

Протокол между частями — [`docs/PROTOCOL.md`](docs/PROTOCOL.md).

## Играть

1. Скачай архив из [Releases](../../releases), распакуй, запусти `SlBridgeLauncher.exe`.
2. Вкладка **«Подготовка»** — пройди шаги: SCP:SL и SCP:SL Dedicated Server из Steam (одной версии),
   Minecraft 26.3 + Fabric (удобнее через [Prism Launcher](https://prismlauncher.org)), кнопка «Установить мод».
3. Вкладка **«Играть»** — выбери или создай мир, нажми «Играть». В SL: Play → Direct connect → Ctrl+V.

Если оверлей что-то перекрывает: **Ctrl+Shift+F12** — выключить/включить, **Ctrl+Shift+F11** — показать маску.
**Ctrl+Shift+F10** — быстрый выход (закроет SL, Minecraft с сохранением, сервер и оверлей; то же — кнопка «Выйти» в SL: Esc → Настройки → Server-specific).

При первом входе в мир у тебя деревянный мультитул (ломать блоки и бить) и одна аптечка — остальное крафтится; ещё раз — `.kit start` в консоли (`~`). При смерти всё, включая предметы SL, выпадает на землю предметами Minecraft (`.mc gamerule keep_inventory true` — сохранять). Инвентарь SL хранится в папке мира и возвращается при следующем входе.

## Управление

Основные настройки (роль, прыжок, свет, зелёный экран, производительность) — в лаунчере, вкладка **«⚙ Настройки»**. Кнопки моста задаются в SL: **Esc → Настройки → Server-specific**. Лаунчер прописывает их сам при первом запуске; поменять можно там же.

| Клавиша | Что делает |
|---|---|
| ходьба, бег, прыжок, присед, Tab, M | как в SCP:SL (инвентарь SL, админ-панель) |
| ЛКМ / ПКМ | стрельба и удар; по блоку — ломает его, по мобу — урон |
| **E** | взаимодействие Minecraft: поставить блок из руки, дверь, рычаг, кнопка, еда, огниво, ведро, око Эндера, кровать; открыть верстак, печь, сундук |
| зажать **E** на предмете | подобрать предмет Minecraft с земли |
| **Q** | выбросить предмет (становится предметом Minecraft) |
| **K** | инвентарь Minecraft с крафтом 2×2 |
| **U** | книга крафтов SL — рецепты в стиле Minecraft (закрыть: U или Esc) |
| **O** | настройки Minecraft (закрыть: O или «Готово») |
| **F4** / **F4+B** / **F4+G** | экран отладки Minecraft / хитбоксы / границы чанков (F3 в SL занят своей отладкой) |
| `~` → `.mc <команда>` | команда Minecraft, например `.mc time set day`; в админ-панели — `mc time set day` |
| `~` → `.kit start` | стартовый набор ещё раз |
| Ctrl+Shift+F10 | быстрый выход (или кнопка «Выйти» в Server-specific) |
| Ctrl+Shift+F12 / F11 | выключить оверлей / показать маску зелёного экрана |

В окнах Minecraft (верстак, инвентарь, сундук) предметы таскаются мышкой, закрыть — **E** или **Esc**.

## Механики

* **Мир.** Блоки — настоящие препятствия для SL: по ним ходишь, о них спотыкаешься, сквозь них не пройти. Стрельба и удары ломают блоки (твёрже блок — больше попаданий), выпадает то же, что и в Minecraft.
* **Мобы.** Урон по ним считает Minecraft (урон SL делится на 5), они бьют тебя в ответ — урон приходит в SL. Эндермены уворачиваются от пуль, как от стрел. Броня SL работает как броня Minecraft.
* **Ближний бой как в SL.** Мачете и Jailbird бьют по области перед собой: главная цель — полный урон, остальные — мачете половину, Jailbird полный. Рывок Jailbird останавливается о моба; дубинка изнашивается, и сломанная взрывается на последнем рывке.
* **Мультитулы.** Меч + кирка одного материала на верстаке → мачете SL этого уровня: от дерева до незерита растут урон и скорость копания (золото копает быстрее всех, но бьёт слабо). При взятии в руку — подсказка с уровнем. На старте — деревянный.
* **SCP-268 (кепка)** делает невидимым и для мобов Minecraft: они теряют тебя из виду, пока эффект действует.
* **SCP-127** растёт от урона по мобам, за убийство — бонус опыта, патроны в магазин и фраза, как за убийство человека. За боссов — свои «комментарии»: хранитель — как за SCP-939, дракон Края — как за SCP-106, иссушитель — как за SCP-049 (если 127 уже «подружился» с тобой).
* **Полоска здоровья босса** (дракон, иссушитель) видна вверху экрана.
* **Роль** в мире Minecraft выбирается в лаунчере, вкладка «⚙ Настройки»: класс D (по умолчанию), обучение, научный сотрудник, охрана, МОГ, Повстанцы Хаоса (их форма зелёная — местами может просвечивать). **Micro H.I.D.** — урон и дальность как в игре. **Гранаты и SCP-018** взрывают и мир Minecraft.
* **Вода и лава.** Всплываешь сам; присесть или идти медленно — нырнуть; к берегу просто подплыви. Вода гасит урон от падения. Лава жжёт, огонь гаснет после смерти.
* **Лестницы и лианы.** Смотришь вверх — лезешь, вниз — спускаешься, прямо — висишь. Урона от падения на них нет.
* **Падение** — по правилам Minecraft: урон = высота − 3 блока (сено, мёд, кровать, слизь смягчают).
* **Темнота настоящая.** Держи в руке включённую **лампу** (светит вокруг) или **фонарик** (свет на несколько метров впереди).
* **Порталы и телепорты.** Незер, Энд, жемчуг Эндера, `/tp` — всё работает: на месте прибытия мир достраивается, и тебя отпускают.
* **Кровать** — ночью сон до утра, в любое время — точка возрождения.
* **Смерть.** Всё, включая предметы SL, выпадает предметами Minecraft (`.mc gamerule keep_inventory true` — сохранять). Возрождение — у кровати или на спавне.
* **Инвентарь SL** хранится в папке мира и возвращается при следующем входе; у каждого мира свой. Состояние предметов (обвесы, патроны в магазине, заряд Micro H.I.D., износ Jailbird, уровень SCP-127 и мультитула) сохраняется везде.
* **Голода нет** — еда идёт на аптечки (см. крафты). Опыт подбирается сам.

## Оптимизация

Две игры делят одну видеокарту, а картинку собирает оверлей (он сам почти ничего не стоит — доли миллисекунды на кадр). Лишние кадры одной игры отнимают их у другой, поэтому:

* **Ограничь FPS до 60 в каждой игре** — в настройках графики SCP:SL и в настройках Minecraft (**O** в игре). Обычно это заметно поднимает реальную плавность.
* Вертикальную синхронизацию в Minecraft лучше выключить, Sodium — включить (галочка в лаунчере).
* Графику SL можно ставить низкую: SL рисует только оружие и интерфейс, мир рисует Minecraft.
* Ещё больше FPS: `"McRenderScale": 0.75` в `dist/compositor/compositor.json` — Minecraft рисует почти вдвое меньше пикселей (мир чуть мягче, окна крафта — в полном размере).

## Крафты

Все рецепты есть и прямо в игре: **U** открывает книгу крафтов SL в стиле окон Minecraft — с настоящими предметами и подсказками при наведении. В лаунчере на вкладке «⚒ Крафты» рецепты тоже нарисованы иконками предметов (их лаунчер берёт из установленного Minecraft).

Все предметы SL крафтятся на верстаке Minecraft (E по верстаку). Готовый предмет сразу становится настоящим предметом SCP:SL в инвентаре; патроны добавляются по 80 штук. Форму можно отражать по горизонтали, а маленькие формы ставить в любое место сетки. Ванильные железная и алмазная кирасы заменены лёгкой и боевой бронёй SL (в мосте броня Minecraft всё равно берётся из брони SL). В темноте Minecraft темно по-настоящему — скрафти лампу и держи её включённой в руке (или фонарик — он светит узким лучом туда, куда смотришь). В окнах Minecraft видны и твои предметы SL — Micro H.I.D., дубинку и молекулярный разрушитель можно перезарядить на верстаке. Рисунки есть и в лаунчере, вкладка «⚒ Крафты».

Обозначения: `#` — Железный слиток, `B` — Железный блок, `D` — Алмаз, `N` — Незеритовый слиток, `G` — Порох, `S` — Палка, `R` — Редстоун, `T` — Факел, `X` — Динамит, `L` — Светокаменная пыль, `U` — Сахар, `O` — Пузырёк, `C` — Какао-бобы, `E` — Паучий глаз, `M` — Слизь, `H` — Кожаный шлем, `P` — Жемчуг Края, `F` — Цветочный горшок, `I` — Плотный лёд, `Y` — Синий лёд, `W` — Миска, `K` — Нотный блок, `V` — Око Края, `Q` — Стеклянная панель, `A` — Стекло, `Z` — Медный слиток, `J` — Уголь, `r` — Блок редстоуна, `w` — Меч (любой материал), `p` — Кирка того же материала, `*` — Этот же предмет (разряженный), `·` — пусто.

## Сборка из исходников

Нужны: .NET SDK 8+, JDK 25, Windows (для оверлея и лаунчера — Windows 10 1903+).

```powershell
# плагин SL (берёт библиотеки игры из SCP:SL Dedicated Server в Steam; другой путь: -p:SLManaged=...)
dotnet build -c Release src/sl-plugin

# рецепты предметов SL (генерирует datapack мода, языковые файлы и таблицу для лаунчера)
python3 tools/gen_recipes.py src/fabric/src/main/resources src/launcher crafts
# мод Minecraft
cd src/fabric; ./gradlew build; cd ../..          # → src/fabric/build/libs/slbridge-fabric-*.jar

# оверлей и лаунчер
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true src/compositor
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true src/launcher
```

Раскладка для лаунчера: рядом с `SlBridgeLauncher.exe` — папка `dist/` с `SlBridge.dll`, `slbridge-fabric-*.jar`,
`fabric-api-*.jar` ([Modrinth](https://modrinth.com/mod/fabric-api)) и `compositor/SlBridgeCompositor.exe`.

## Безопасность

* Клиент SCP:SL и античит не трогаются: оверлей только **захватывает изображение окон** (Windows Graphics Capture)
  и рисует поверх, клики проходят сквозь него.
* Сеть: только `127.0.0.1` (мост между плагином и модом, порт 25599) и локальный сервер SL (7777).
